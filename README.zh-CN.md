# 文件夹体检器

[English](README.md)

一个适用于 Windows 10/11 的离线、只读文件夹扫描工具。它不会删除、移动、重命名或修改被扫描目录中的内容，也不会连接网络。

它解决的问题很简单：当一个文件夹越来越乱、越来越大时，快速告诉你“空间都去哪了”。

## 功能

- 文件总数、文件夹总数和总大小
- 按扩展名统计数量和空间
- 最大的 50 个文件
- 重复文件：先按大小筛选，再读取内容并以完整 SHA-256 确认
- 超过约 2 年未修改的文件
- 空文件夹
- PNG、JPEG、GIF、BMP 图片宽高（仅使用 Python 标准库）
- 如果系统已有 `ffprobe`，读取常见视频的时长、分辨率和编码
- 无法访问、文件被占用、元数据读取失败等错误写入报告，不让整个扫描崩溃
- HTML 表格可点击表头排序，同时生成 CSV

## 安全与隐私

- **只读**：不删除、移动、重命名或修改文件
- **离线**：不进行网络请求
- **范围明确**：只扫描用户明确选择的文件夹
- **符号链接会跳过**，避免意外扫描到目标目录之外
- 报告只写入项目本地的 `reports` 文件夹

报告会包含文件的完整路径、大小、修改时间，以及重复文件的 SHA-256。分享报告前请确认其中没有敏感路径信息。

## 系统要求

- Windows 10 / Windows 11
- Python 3.10+
- 可选：`ffprobe`（仅用于读取视频元数据）

没有必需的第三方 Python 依赖。

## 使用方法

### 方法一：拖拽

把要检查的文件夹拖到 `run.bat` 上。

### 方法二：双击

双击 `run.bat`，粘贴文件夹路径并回车。

### 方法三：命令行

```text
py -3 src\folder_health_checker.py "D:\要检查的文件夹"
```

扫描完成后，在项目的 `reports` 文件夹中打开 `report.html`，也可以用 Excel 等工具打开 `report.csv`。

每次普通运行会覆盖项目内上一份 `report.html` 和 `report.csv`，不会改动被扫描目录。

## 测试

```text
py -3 -m unittest discover -s tests -v
```

测试会在 `work/` 中创建自己的临时数据，结束后清理。

## 本地生成模拟数据

```text
py -3 scripts\create_example.py
```

它只会在 `work/example_data` 创建模拟文件，并在 `reports/` 生成示例报告。`work/` 和 `reports/` 都已被 Git 忽略，避免本机完整路径被意外提交。

## 已知限制

- 特别大的目录可能需要较长时间，因为重复文件候选最终需要完整读取文件计算 SHA-256。
- Windows 权限限制、独占占用或路径策略可能导致部分文件无法读取；错误会进入报告，不会终止整个扫描。
- Windows 目录联接 / reparse point 在不同存储、同步盘环境下还没有做足够广泛的验证；符号链接会明确跳过。
- 没有 `ffprobe` 时会跳过视频元数据。

## 项目文件

- `src/folder_health_checker.py`：扫描及报告生成程序
- `run.bat`：Windows 启动入口
- `tests/`：自动化测试
- `scripts/`：EXE 构建脚本与模拟数据生成器
